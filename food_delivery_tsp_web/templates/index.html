HOW THE TSP SOLVER WORKS

One depot. Every stop. A closed loop.

For a selected depot d and delivery set V, the solver chooses an ordering that minimizes the sum of directed matrix costs along the route, including the return to the depot.

min Σ c(vi, vi+1)   with   v0 = vn+1 = d
  • Exact enumeration for small instances
  • Held–Karp dynamic programming for moderate instances
  • Nearest-neighbor with 2-opt for larger selections, labelled heuristic
